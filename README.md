# Chhattisgarh Tourist Guide Platform (MERN Stack)

A full-stack web platform connecting tourists visiting Chhattisgarh with certified, knowledgeable local guides.

## Tech Stack
- **Frontend**: React.js (Vite), React Router v7, Tailwind CSS v4, Axios, Lucide React
- **Backend**: Node.js, Express.js (REST API, ES6 Modules)
- **Database**: MongoDB (Local `mongodb://127.0.0.1:27017/chhattisgarh_tourism`)
- **Authentication**: JWT (JSON Web Tokens), Bcrypt.js

## Project Structure
```text
d:\Mini Project\
├── server\        # Express API & MongoDB Models
└── client\        # React Frontend with Tailwind CSS
```

## How to Run

### 1. Backend Server
```bash
cd server
npm run dev
```
Server runs on: `http://localhost:5000`

### 2. Frontend Client
```bash
cd client
npm run dev
```
Client runs on: `http://localhost:5173`
